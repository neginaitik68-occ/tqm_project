Accessibility Testing

This module evaluates the accessibility and usability of the Restaurant Billing System according to customer requirements and Total Quality Management principles.

Accessibility Test Cases

Test ID Feature Test Description Expected Result Actual Result Status
AT-01 High Contrast Enable High Contrast mode and inspect text, buttons and interface elements. Content should become easier to distinguish. To be tested Pending
AT-02 Font Resizing Increase and decrease the font size. Text should resize without breaking the layout. To be tested Pending
AT-03 Keyboard Navigation Navigate through controls using Tab, Shift + Tab and Enter. Important controls should be accessible without using a mouse. To be tested Pending
AT-04 Dark Mode Enable and disable Dark Mode. Interface should switch themes correctly. To be tested Pending
AT-05 Minimalist Layout Check whether important functions are easy to locate. Users should be able to understand and navigate the interface easily. To be tested Pending
AT-06 Billing Functionality Add, remove and modify food items. Bill should update correctly. To be tested Pending
AT-07 Total Calculation Change item quantities and check the total. Total should recalculate correctly. To be tested Pending
