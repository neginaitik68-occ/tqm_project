Cashier / Staff Module

Cashiers are internal customers because they directly use the restaurant billing system to process customer orders and payments.

Cashier Responsibilities

Select Items

Cashiers should be able to quickly select food and beverage items.

Manage Quantity

Cashiers should be able to increase or decrease item quantities easily.

Manage Bill

Items should be added, removed and cleared easily.

Process Checkout

The cashier should be able to complete checkout without unnecessary steps.

Cashier Quality Requirements

Requirement System Feature Quality Goal
Fast Item Selection Menu buttons Reduce billing time
Quantity Handling Quantity controls Easy order modification

Reliable Calculation Automatic subtotal, tax and total Reduce calculation errors
Easy Checkout Checkout function Efficient transaction processing
